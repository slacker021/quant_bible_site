# The Quant's Bible
This repository holds the web component of the _Quant's Bible_, with the other repository (https://github.com/slacker021/quant_bible_notes.git) being responsible for holding the actual markdown documents to be rendered via this website. This website is an open-access project that aims to make learning quantitative finance, from the perspective of an independent quant researcher, viable. 

### Technical Specifications
- **Hosting Platform:** This website is hosted using _Vercel_.
- **Publishing Platform:** The notes are published through the use of the _Digital Garden_ plugin for _Obsidian_. This allows for easy control of the various settings without the need for manual coding.

### Plugins Used
- **Theme:** _Noir Void_, a sleek dark theme created by _CosmicSeaFox_ that is easy on the eyes.
- **Copy and Paste Code:** _Copy Code Button_, a button located near each code block that enables the reader to copy the code and paste it into their text editor of choice. This was created by _Ole Eskild Steensen_. 
- **Printing Option:** _Clean Print_ by _Kolten Bendickson_ enables the reader to print the page, should they desire to have a hard copy. Note that the printed version is in white, as opposed to the dark monochromatic scheme this website uses.
- **Commenting:** _Giscus Comments_ was created by _Ole Eskild Steensen_ to allow the reader to comment on whatever page they are reading. Note that commenting requires the reader to have a Github account.
- **Image Inspection:** _Image Lightbox_ by _Ole Eskild Steensen_ allows the reader to click on an image and more closely inspect it.
- **Progress Checking:** _Reading Progress & Resume_ by _Kolten Bendickson_ gives the reader an idea of how far they are into the page they are reading through a small progress bar on the top of the screen.
- **Element Resize:** _Resizable Panes & Reading Width_ by _Kolten Bendickson_ allows the reader to change the width of the left and right sidebar so they can more easily read whatever is entered into the main body.
- **Sidebar Management:** _Sidebar Controls_ by _Ole Eskild Steensen_ allows the reader to toggle the left and right sidebar for a more immersive reading experience
